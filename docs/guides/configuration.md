# 配置说明

优先使用设置界面；内部环境变量不等于稳定的用户配置接口。不要把生产密钥写入 Markdown、测试快照或 Git。

| 设置 | 用途与边界 |
| --- | --- |
| 麦克风和采集来源 | 固定实体设备；选择麦克风、电脑声音或两者。默认设备可能是 Sonar 虚拟设备，要看实际音量/来源状态 |
| 应用音轨 | 开关、音轨数量上限（1–8）、降级策略；系统不支持或应用不可采集时保留混音且标记未知 |
| 保留模式 | 语音触发带前后缓冲，或会议连续录制；转写/总结保存期不等于原音频保存期 |
| 资源治理 | 游戏优先、平衡、处理优先；高级设置可调外部 GPU 阈值与恢复等待时间 |
| 本人声纹 | 本地引导录入/复核；未知说话人和媒体不能用于无条件更新 SELF |
| MiniMax | 配置支持的 endpoint、模型和 Key；订阅 Key 与通用 API 能力/计费不能互相假设 |
| 云预算 | 个人助手分析预算可设金额或不设上限；Spent 与 Reserved 都要看，未知用量可能阻止继续请求 |
| 转写云纠错 | 与 MiniMax 文本总结分开；启用后可能上传可疑音频片段，需单独确认对应提供商和预算 |
| 规则与通知 | 本地个性化规则、学习目标、正式待办提醒、专注模式和临时静音 |

本地转写模型选择由 `app/src/jarvis/main/JarvisWhisperModel.js` 决定：优先可用的 `JARVIS_WHISPER_MODEL`、`LOCAL_WHISPER_MODEL`，再依次检查 turbo、large、medium、small、base。默认名称为 turbo；安装了哪个模型与当前实际加载哪个模型需要分别验证。

存储根目录由 `DataRootConfig` 与启动恢复流程选择，启动后设置 `JARVIS_DATA_ROOT` 供模型/helper 使用。不要仅通过设置该变量就假设整个应用已经切换数据库。变更数据目录应通过应用的迁移流程；开发和烟测用独立目录，禁止复用生产数据。

开发时明确将 `TEMP`、`TMP`、`npm_config_cache`、`ELECTRON_CACHE` 和 `electron_config_cache` 指向 G 盘，见[开始使用](getting-started.md)。密钥/声纹加密可用性依赖操作系统账户和密钥存储；复制数据库不等于能在另一台电脑直接解密。
