# Jarvis 会话参与者与人物复核实施计划

- 日期：2026-07-30
- 状态：用户逐项批准，进入实施
- 基线版本：`0.2.0-alpha.28`
- 工作区：`G:\Jarvis\.worktrees\jarvis-all-day-runtime`

## 目标

把当前“每条音轨产生若干 Speaker 簇”的技术结果，转换成用户可以信任的三层结果：

1. 原始声纹簇：只用于技术诊断，普通界面默认隐藏。
2. 本次会话参与者：跨应用音轨、捕获代次和系统混音去重后的会话人物。
3. 长期人物：经过双模型一致、足够语音证据或用户明确确认的人物档案。

人数只统计与用户实际互动且在本次会话中发言的人。游戏、视频、直播和解说归入媒体声音，不进入 People；应用来源只参与活动语境判断，不预设人数。

## 已批准的产品门禁

- 未完成复核前显示人数范围，并拆分为“我 + 其他参与者”。
- 会话候选门槛：至少 5 秒清晰语音或 3 次独立发言。
- 长期匿名人物门槛：累计至少 20 秒清晰、非重叠语音，分布在至少 3 个片段，CAM++ 与 ERes2NetV2 都有有效证据。
- 双模型高置信度一致时可自动关联匿名人物；涉及已命名人物、SELF 冲突或低置信度时进入待复核。
- 重叠且无法可靠分离的语音保留转写，但不更新声纹、不归属 Todo。
- 每个待复核人物默认提供三个代表片段：清晰片段、不同时间片段、最易混淆片段。
- 支持按片段拆分、人物合并、媒体标记、历史影响预览与撤销。
- 原始音频和代表片段遵守 7 天删除；只有用户主动固定的证据片段可以长期保留。
- 有原始音频的历史会话分阶段回溯；没有音频时只清理遗留碎片，不猜测身份。

## Task 1：建立会话参与者公共投影

新增纯本地 `SessionParticipantProjector`，输入最新高精度说话人运行、双模型身份结果、音轨来源、重复关系和活动分类，输出：

- 已确认人物、长期匿名人物、临时参与者、媒体声音、证据不足碎片。
- 会话人数最小值、最大值、已确认数、待复核数和 SELF 是否实际发言。
- 每个参与者对应的原始 cluster、音轨、片段、语音时长、模型一致性和来源集合。
- 系统混音与精确应用轨的重复排除理由。

公共投影不得直接把原始 cluster 数量当人数；超过合理技术上限的旧数据应返回异常状态，而不是无限重试或展示几百个人。

## Task 2：持久化人物复核与历史变化

数据库迁移新增：

- 会话参与者快照及 cluster 成员关系。
- 人物复核事件：确认、拆分、合并、媒体标记、忘记身份、撤销。
- 复核影响预览和历史回溯批次。
- 可选固定证据片段元数据；默认不改变 7 天音频保留策略。

迁移必须幂等，保持旧 `speaker_clusters`、identity resolution、transcript evidence 和 voice profile 外键完整。

## Task 3：代表片段与修正服务

新增类型化接口：

- 获取本次会话参与者概览。
- 获取待复核队列。
- 获取人物三个代表片段及完整时间线。
- 将 cluster 或选定 transcript segment 拆分为新人物。
- 合并人物并预览历史影响。
- 标记为媒体声音。
- 忘记身份或删除人物关联记录。
- 撤销最近一次复核操作。

代表片段优先选择无重叠、非回声、来源明确、质量高且分布于不同时间位置的片段。

## Task 4：Memory 会话人物 UI

在会话总结顶部显示：

- `预计 3–4 人（我 + 2–3 位其他参与者）`
- `已确认 N · 待复核 N`
- `已排除 N 个媒体声音或重复声纹碎片`
- 初次结果与后台复核结果的变化原因

普通界面显示人物卡片而不是 `speaker_113`。点击卡片进入复核抽屉，提供三个可播放证据、转写、应用、时间和确认操作；原始簇只在“技术详情”中展开。

## Task 5：People 四区 UI

People 页面固定为：

1. 我
2. 常见人物
3. 未命名人物
4. 待复核

临时参与者不进入 People。人物详情显示互动次数、最近互动、主题、承诺和证据跳转；关系类型只作为候选建议，未经用户确认不能成为事实。

## Task 6：历史清理与分阶段回溯

- 最近仍有音频的会话先回溯并验证。
- 通过门禁后再批量处理其他仍有音频的会话。
- 无音频旧会话清理零语音、零窗口、非最新运行和旧音轨风暴产生的公共投影。
- 旧总结默认保留；人物或转写发生实质变化时只标记“建议刷新总结”。
- 展示旧人数、复核后人数、合并/排除原因和可撤销状态。

## Task 7：测试、真实数据验证与发布

自动化验证：

- 跨音轨代次的同一匿名人物只计一次。
- 精确应用轨与系统混音重复时只计一次。
- 媒体声音不进入社交人数和 People。
- SELF 只有实际发言时才计入人数。
- 证据不足和重叠语音保持临时/未知。
- 人数范围、后台修正原因、拆分、合并、撤销和 7 天保留门禁正确。
- 旧的几百个 cluster 不再投影成几百个人。

真实数据验证：

- 对最近 KOOK、DOTA 2、腾讯会议和麦克风会话生成前后对照。
- 核对 CAM++、ERes2NetV2、SELF、匿名人物和应用来源证据。
- 不对生产数据库直接做不可逆修改；先备份到 G 盘并使用迁移后的副本验证。

发布前运行 Jarvis 主进程测试、renderer 测试、typecheck、lint、打包和 Windows unpacked 启动验证，再更新 alpha 版本。
