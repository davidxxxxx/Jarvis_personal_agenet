# Jarvis rc.13 模块整理计划

范围：从 rc.12 提取职责明确的模块，保持录音、持久化、隐私门禁和 UI 行为；不启动应用、不改生产数据库、不调用付费服务。

1. 核对当前功能、代码入口和验证边界，提供面向使用者及开发者的文档索引。
2. 将后台运行器、组装工厂、实时预览分离，保留 `JarvisProcessingRuntime.js` 兼容入口。
3. 从 IPC 分离公开数据投影；从仓储分离说话人音轨选择、分析校验；不改变事务及 schema v60。
4. 从 Memory 页面提取展示模型与总结组件，保留既有导出和交互。
5. 新增模块边界/契约测试，运行主进程、渲染器、类型、lint 和构建检查。
6. 更新 rc.13 版本及变更说明，审查秘密及生成物，提交并推送到用户 origin；沿用 PR #1。

验收：自动化回归通过；新模块不反向依赖原来的入口/仓储/UI 容器；源代码与文档可导航。真实声纹准确率、实体设备连续录音、CUDA 及长时耐久、安装包验收不由本次重构测试代替。

后续：两个大仓储的事务和历史迁移保留原处，避免一次搬动所有 SQL。以后按单一业务用例逐步提取事务仓储，不能宣称已完全消除全部大文件。
